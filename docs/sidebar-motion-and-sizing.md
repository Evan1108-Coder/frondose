# Sidebar sizing and interface motion

The main workspace sidebar and the Settings rail use one browser-local width. The default desktop width is 240px; explicitly saved widths are preserved. Navigation retains 14px labels and 32px standard rows. On desktop, drag the rail's right edge or focus its separator and press Left/Right to change the width in 24px increments. End enters a full-width navigation mode; Home hides the rail. A hidden rail can be restored with the header's Show navigation button, or temporarily revealed by hovering at the far left edge. Selecting a destination closes the temporary reveal. Mobile retains its separate 260px-bounded drawer and does not use the resize handle.

In normal mode, desktop width is bounded between 200px and 62% of the viewport, leaving at least 300px of room for the page. Dragging to within 72px of the left edge hides the rail while preserving the width it had before the drag. Dragging beyond 80% of a viewport at least 1000×600 enters full-width navigation mode. The active page becomes a small, slightly tilted preview. Use its Move/Resize handles (pointer or arrow keys), or click Open page to restore the normal layout. The preview itself is inert, so tiny scaled controls cannot be activated accidentally. The mode is temporary; the normal width and hidden state are personal to this browser and do not change shared workspace data. On smaller viewports, the full-width mode is unavailable and the ordinary width cap remains.

Dialogs reveal their actual-size content through a small clipped shell near the opening control. Expansion takes 240ms and pointer dismissal contracts in 160ms; travel from distant controls is capped at 96px per axis. Closing during entrance starts from the visible frame. Guarded dirty-draft closes restore the same mounted dialog rather than leaving an invisible discard question. Command palettes and keyboard-driven actions remain immediate. OS or app reduced motion uses at most an 80ms fade with no clipped expansion or spatial travel; changing those preferences cancels in-flight movement.

Single-choice connection filters share SlidingTabs. The selected indigo plate slides in 220ms while the filter value updates immediately; text does not scale. A radio group exposes checked state, one Tab stop, arrow/Home/End selection, disabled skipping and RTL direction. Keyboard and reduced motion snap the plate to the selected choice. A selected page gets one short upward entrance; live data refreshes do not replay it. The sidebar and Settings rail use a static, barely tinted gradient; the main canvas remains nearly neutral.

This is a bounded layout preview, not a separate browser window. Dragging or resizing it changes only the on-screen preview; the page returns to its actual size before it can be interacted with.
