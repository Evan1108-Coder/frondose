# Writing-first editors

Scope: shared input dialogs, EntityDialog, profile identity. Mode: Operate.

## Direction contract

THESIS: Write first, set properties second; avoid a narrow tower of equally weighted boxes.

OWN-WORLD: Inherit Frondose's Inter, neutral theme surfaces, thin outline glyphs and indigo actions. The user's Linear screenshot governs editor anatomy, not third-party branding.

STORY: Open an editor, write a name and details, choose compact properties, then deliberately save. Expansion preserves the same draft. Files use real supported storage only.

FIRST VIEWPORT: A wide rounded panel with a quiet context header and expand/close controls. Full-width title and description lead; horizontal property controls wrap below. Supporting settings remain readable. The primary action sits bottom-right. Narrow screens stack writing areas and wrap controls without page overflow.

FORM: User-pinned screenshot, code-led local extension; no concept tournament or identity replacement. Seed: none (user-pinned).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
