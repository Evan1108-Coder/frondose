# Service marks

Google Docs, Sheets, and Slides PNG marks are bundled from Google's own static asset service:

- https://ssl.gstatic.com/docs/doclist/images/mediatype/icon_1_document_x128.png
- https://ssl.gstatic.com/docs/doclist/images/mediatype/icon_1_spreadsheet_x128.png
- https://ssl.gstatic.com/docs/doclist/images/mediatype/icon_1_presentation_x128.png

Other service marks use the bundled SVG Logos collection via `@iconify-icons/logos`. FigJam is identified by its provider Figma's mark. GitHub Packages uses GitHub's mark. These identify third-party products; they do not imply endorsement.
